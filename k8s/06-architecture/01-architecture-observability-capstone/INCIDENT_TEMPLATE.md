## 2. 감지 및 시간선

| 시각 | 관찰된 현상 | 근거 / 명령 |
|---|---|---|
| T0 | 정상 응답 | HTTP 코드, Pod Ready, EndpointSlice |
| T1 | 장애 주입/감지 | 변경 내용 및 실행 명령 |
| T2 | 첫 증거 수집 | get/describe/events/logs |
| T3 | 원인 후보 축소 | 반증 성공/실패 |
| T4 | 복구 조치 | 최소 변경 사항 |
| T5 | 복구 검증 | 사용자 요청 재시도 및 재발 확인 |

## 3. 가설과 증거

| 가설 | 맞다면 관찰될 증거 | 실제 관찰 | 판단 |
|---|---|---|---|
| DNS 오류 | 이름 해석 실패 | | |
| Service selector 오류 | EndpointSlice에 사용 가능한 backend 없음 | | |
| Readiness 실패 | Running이지만 Ready=False | | |
| 스케줄링 실패 | Pending과 FailedScheduling Event | | |
| 앱/Port 오류 | Ready·Endpoint 정상인데 Pod 직접 요청 실패 | | |

증상에서 확실히 알 수 있는 사실과 추정한 원인을 문장으로 구분한다.

## 6. 학습 회고

- 첫 번째 가설이 틀렸다면 왜 그렇게 생각했는가?
