# 48. Amazon Textract

Amazon Textract는 **scanned document에서 text, handwriting, form, table 데이터를 자동 추출**하는 AI/ML 서비스다.

## 기본 구조

```text
PDF / Image / Scanned Document
            ↓
         Textract
            ↓
Text / Handwriting / Forms / Tables
            ↓
Structured Result
```

## 강의 use case

```text
Financial Services
→ invoices / financial reports

Healthcare
→ medical records / insurance claims

Public Sector
→ tax forms / ID documents / passports
```
