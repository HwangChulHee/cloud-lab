# u2. Lex Chatbot / Call Center Bot

강의에서 Lex의 대표 use case는 다음 두 가지다.

```text
Chatbot
Call Center Bot
```

예:

```text
User
"예약하고 싶어요"
   ↓
Lex
   ↓ intent recognized
ScheduleAppointment
```

Lex는 대화 입력을 받고 intent를 판별해 이후 Lambda나 backend 처리로 연결할 수 있다.

## 기억할 문장

> 대화형 인터페이스에서 사용자의 의도를 파악하고 다음 작업으로 연결하면 Lex다.
