# 46. Amazon Lex

Amazon Lex는 **대화형 챗봇/콜봇**을 만들기 위한 서비스다.

강의에서는 Alexa와 같은 기술을 사용한다고 설명한다.

- [ ] [u1. ASR / NLU](./u1_asr_nlu/README.md)
- [ ] [u2. Chatbot / Call Center Bot](./u2_chatbot_callcenter/README.md)
- [ ] [u3. Amazon Connect Integration](./u3_connect_integration/README.md)
- [ ] [u4. SAA Selection](./u4_saa_selection/README.md)

## 핵심

```text
Speech / Text
   ↓
Amazon Lex
   ├→ ASR: speech → text
   └→ NLU: intent 이해
   ↓
Chatbot / Call Center Bot
```

## 한 줄 기억

> 말을 글로만 바꾸는 것은 Transcribe, 사용자의 의도를 이해해 대화형 bot을 만드는 것은 Lex다.
