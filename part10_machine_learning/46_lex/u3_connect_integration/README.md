# u3. Amazon Connect Integration

Amazon Connect는 **cloud-based virtual contact center**다.

강의에서는 다음을 설명한다.

```text
Receive Calls
Create Contact Flows
CRM / AWS Integration
```

Lex와 함께:

```text
Phone Call
   ↓
Amazon Connect
   ↓
Amazon Lex
   ↓ intent recognized
Lambda / CRM
   ↓
Schedule / Action
```

처럼 call-center automation을 구성할 수 있다.

## 핵심 구분

```text
Lex
→ bot / intent recognition

Connect
→ cloud contact center
```
