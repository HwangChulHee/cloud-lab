# u1. Lex ASR / NLU

강의에서는 Lex의 두 핵심 기술을 구분한다.

```text
Automatic Speech Recognition (ASR)
→ speech를 text로 변환

Natural Language Understanding (NLU)
→ text/caller의 intent를 이해
```

즉 Lex는 음성 변환만 하는 것이 아니라 **의도 이해**까지 연결한다.

## Transcribe와 차이

```text
Transcribe
→ speech → text

Lex
→ speech/text → intent
→ conversational bot
```
