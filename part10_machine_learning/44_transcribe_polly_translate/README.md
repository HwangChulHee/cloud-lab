# 44. Amazon Transcribe / Polly / Translate

이 단원은 **음성 ↔ 텍스트 ↔ 언어 변환** 서비스를 구분한다.

```text
Transcribe
→ Speech → Text

Polly
→ Text → Speech

Translate
→ Text in Language A → Text in Language B
```
