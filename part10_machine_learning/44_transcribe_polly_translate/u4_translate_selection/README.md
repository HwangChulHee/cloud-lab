# u4. Amazon Translate / SAA Selection

Amazon Translate는 **자연스럽고 정확한 language translation**을 제공하는 서비스다.

강의에서는 다음 목적을 강조한다.

```text
website localization
application localization
large volumes of text translation
international users 지원
```

## 최종 비교

```text
Speech → Text
→ Transcribe

Text → Speech
→ Polly

Text Language A → Language B
→ Translate
```

## 기억할 문장

> 음성 인식은 Transcribe, 음성 합성은 Polly, 다국어 텍스트 번역은 Translate다.
