# u1. SageMaker — Managed ML Platform

강의는 SageMaker를 다음처럼 설명한다.

```text
Fully Managed Service
for Developers / Data Scientists
to Build ML Models
```

ML에서는 보통:

```text
data 준비
model build
training
tuning
prediction
infrastructure provisioning
```

등 여러 과정이 필요하다.

SageMaker는 이 과정을 한 managed environment에서 수행할 수 있게 한다.

## 이 파트의 깊이

SAA에서는 모델 알고리즘 구현보다 **"직접 ML model을 build/train해야 한다"면 SageMaker**라는 선택 기준이 중요하다.
