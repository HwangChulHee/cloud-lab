# u4. SageMaker SAA Selection

```text
자체 ML model build/train
→ SageMaker

개발자/data scientist용 managed ML platform
→ SageMaker

이미 준비된 image analysis API
→ Rekognition

이미 준비된 NLP service
→ Comprehend

personalized recommendation을 빠르게 구현
→ Personalize
```

## 기억할 문장

> SageMaker는 ML 기능 하나를 제공하는 API가 아니라, ML model을 build/train/tune하고 prediction에 사용하는 managed platform이다.
