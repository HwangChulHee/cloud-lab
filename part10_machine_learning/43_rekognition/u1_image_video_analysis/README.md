# u1. Rekognition Image / Video Analysis

강의에서는 Rekognition이 이미지와 비디오에서 다음을 찾을 수 있다고 설명한다.

```text
Objects
People
Text
Scenes
```

대표 사용:

```text
Labeling
Text Detection
Scene Detection
Pathing
```

예를 들어 스포츠 영상에서 사람이나 객체의 이동 경로를 분석하는 use case도 언급한다.

## 기억할 문장

> 이미지나 영상 자체를 ML로 분석해야 한다면 Rekognition을 먼저 떠올린다.
