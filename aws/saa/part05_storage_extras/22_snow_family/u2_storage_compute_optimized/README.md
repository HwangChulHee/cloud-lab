# u2. Snowball Edge Storage vs Compute Optimized

강의는 Snowball Edge를 두 가지 대표 타입으로 구분한다.

## Storage Optimized

```text
Storage 중심
대용량 data migration
edge storage
```

강의 슬라이드 예시:

```text
104 vCPUs
416 GB memory
210 TB SSD storage
```

## Compute Optimized

```text
Compute 중심
edge processing
```

강의 슬라이드 예시:

```text
104 vCPUs
416 GB memory
28 TB SSD storage
```

## 선택 감각

```text
대량 data 이동/저장
→ Storage Optimized

현장에서 compute 작업 비중이 큼
→ Compute Optimized
```

숫자 자체보다 **storage 중심 vs compute 중심** 차이를 기억한다.
