# 04부 — Route 53, S3 & Global Delivery

SAA 강의의 Route 53, S3, CloudFront / Global Accelerator, ACM 영역을 정리한다.

## 순서

- 13. Route 53
- 14. S3 Core
- 15. S3 Advanced & Security
- 16. CloudFront / Global Accelerator
- 17. ACM / HTTPS

## 실습 우선순위

`aws/labs/`와 직접 연결되는 핵심은 Route 53, S3 Core, S3 Security, ACM/HTTPS다. CloudFront / Global Accelerator는 SAA Coverage를 먼저 확보하고 이후 필요할 때 심화한다.

```text
Route 53 → aws/labs/13
S3 Core / Security → aws/labs/11~12
ACM / HTTPS → aws/labs/13, 16
```
