# u2. Rekognition Face Analysis / Verification

Rekognition은 얼굴 관련 기능도 제공한다.

강의 핵심:

```text
Facial Analysis
Facial Search
User Verification
People Counting
Celebrity Recognition
```

Face Analysis에서는 예시로 다음을 언급한다.

```text
gender
age range
emotions
```

또한 familiar faces database를 만들거나 celebrity와 비교하는 use case도 다룬다.

## SAA 판단

```text
얼굴 존재/특징 분석
→ Rekognition

얼굴 비교/사용자 검증
→ Rekognition

유명인 인식
→ Rekognition
```
