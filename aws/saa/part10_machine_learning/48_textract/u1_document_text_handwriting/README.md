# u1. Textract Document Text / Handwriting Extraction

Textract는 scanned document에서 다음을 자동 추출한다.

```text
Printed Text
Handwriting
Document Data
```

입력 예:

```text
PDF
Image
Scanned Form
```

일반 OCR처럼 글자만 읽는 수준을 넘어서 document data extraction 용도로 설명된다.

## Rekognition Text Detection과 감각적 차이

```text
Rekognition
→ image/video 안의 text/object/scene 분석

Textract
→ scanned document 중심
→ forms / tables / handwriting / structured data extraction
```
