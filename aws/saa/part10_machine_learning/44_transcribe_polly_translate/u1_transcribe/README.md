# u1. Amazon Transcribe

Amazon Transcribe는 **speech를 text로 자동 변환**한다.

강의에서는 Automatic Speech Recognition(ASR)을 사용한다고 설명한다.

## 주요 기능

```text
Speech → Text
PII Redaction
Automatic Language Identification
```

## 대표 use case

```text
customer service call transcription
closed captioning / subtitles
media archive metadata 생성
```

## SAA 판단

```text
음성을 자막/문장으로 변환
→ Transcribe

통화 내용을 text로 바꿈
→ Transcribe

multi-lingual audio의 언어 자동 식별
→ Transcribe
```
