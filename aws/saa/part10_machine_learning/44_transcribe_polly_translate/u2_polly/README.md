# u2. Amazon Polly

Amazon Polly는 **text를 lifelike speech로 변환**한다.

```text
Text
 ↓
Amazon Polly
 ↓
Speech Audio
```

강의 표현대로 "말하는 애플리케이션"을 만들 때 사용할 수 있다.

## 대표 use case

```text
텍스트 읽어주기
voice-enabled application
자동 음성 안내
```

## Transcribe와 반대 방향

```text
Transcribe
Speech → Text

Polly
Text → Speech
```

이 둘은 시험에서 가장 쉽게 헷갈릴 수 있으므로 방향을 기준으로 외운다.
