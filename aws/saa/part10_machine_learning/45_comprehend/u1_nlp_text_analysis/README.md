# u1. Comprehend NLP / Text Analysis

Comprehend는 text에 ML을 적용해 insight와 관계를 찾는다.

강의에서 다음 분석을 언급한다.

```text
language detection
key phrases
places
people
brands
events
tokenization
parts of speech
```

## 대표 구조

```text
Customer Email
    ↓
Comprehend
    ↓
Text Insights
```

## 기억할 문장

> 일반 텍스트의 의미/구조/엔터티를 NLP로 분석하면 Comprehend다.
