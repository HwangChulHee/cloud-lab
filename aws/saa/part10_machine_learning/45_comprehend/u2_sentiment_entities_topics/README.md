# u2. Comprehend Sentiment / Entities / Topics

강의에서 Comprehend의 대표 기능은 **sentiment analysis**다.

```text
Text
 ↓
Comprehend
 ↓
Positive / Negative 등 감정 정보
```

또한 여러 text file collection을 topic별로 자동 정리할 수 있다.

## 대표 use case

```text
customer interactions / emails 분석
→ positive/negative experience 원인 탐색

articles collection
→ topic별 자동 grouping
```

## SAA 판단

```text
고객 리뷰/메일 감정 분석
→ Comprehend

대량 문서에서 topic 발견
→ Comprehend
```
