# u2. Well-Architected Six Pillars

## Operational Excellence

운영하고 변화시키는 능력, 자동화와 지속적 개선을 본다.

## Security

identity, protection, detection 등 workload 보호를 본다.

## Reliability

failure에서 복구하고 요구사항을 지속 충족할 수 있는지를 본다.

## Performance Efficiency

workload 요구에 맞는 resource와 기술을 효율적으로 선택하는지를 본다.

## Cost Optimization

불필요한 비용을 제거하면서 business value를 유지하는지를 본다.

## Sustainability

resource 사용 효율을 높여 workload의 환경 영향을 줄이는 관점이다.

## 기억할 문장

> SAA 문제에서 한 서비스 기능만 보지 말고 보안·가용성·성능·비용·운영 관점을 동시에 생각하는 습관을 만든다.
