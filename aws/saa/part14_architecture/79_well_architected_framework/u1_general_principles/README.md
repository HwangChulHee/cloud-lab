# u1. Well-Architected General Guiding Principles

강의에서 소개하는 일반 원칙:

```text
capacity needs를 추측하지 않는다
production scale에서 test한다
automation으로 architecture 실험을 쉽게 한다
evolutionary architecture를 허용한다
changing requirements에 맞춰 설계한다
data를 기반으로 architecture를 결정한다
game day를 통해 개선한다
flash sale 같은 상황을 simulation한다
```

## 감각

Architecture는 한 번 설계하고 끝나는 정답이 아니다.

```text
Measure
→ Test
→ Learn
→ Change
→ Repeat
```

## 기억할 문장

> Well-Architected의 기본 태도는 추측보다 측정, 수동보다 자동화, 고정보다 지속적 개선이다.
