# 국내 MSP 및 클라우드 운영 기업 목록

> 조사 기준일: 2026-11-06 · **취업/포트폴리오 리서치용 초기 후보군(18개사)**  
> 국내 MSP 전체 목록이나 시장점유율·채용 순위가 아님. 기업의 세부 파트너 등급, 채용 현황, 프로젝트별 기술 스택은 별도 확인이 필요함.

## 분류 기준

- **MSP**: 고객의 클라우드 구축·이관 이후 모니터링, 장애 대응, 보안, 비용 최적화 등 운영 서비스를 제공하는 사업자.
- **전문 MSP·클라우드 서비스 기업**: 클라우드 관리 서비스를 주요 사업 중 하나로 내세우는 업체. SI·보안·솔루션 사업을 함께 수행할 수 있음.
- **대기업 계열 IT서비스/클라우드 기업**: SI·시스템 운영·자체 인프라 사업과 MSP를 병행하는 업체. 전부를 '순수 MSP'로 분류하면 부정확함.
- **CSP와 구분**: AWS·Azure·GCP 같은 인프라 공급자와 고객 인프라를 관리하는 MSP는 역할이 다름.

## 3. cloud-lab 기반 기업 조사 포인트

현재 AWS·Kubernetes·Networking을 학습하는 관점에서, 각 기업의 **공개 고객 사례와 실제 채용공고**를 근거로 다음을 살핀다.

| 관찰 항목 | 확인 질문 |
| --- | --- |
| 클라우드 | AWS/Azure/GCP 비중, 멀티클라우드·하이브리드, Landing Zone/VPC/IAM |
| 컨테이너 | EKS/AKS/GKE/Kubernetes 구축·운영, 배포·업그레이드·장애 대응 |
| IaC/자동화 | Terraform, Ansible, GitOps, CI/CD 사용 사례 |
| 운영/SRE | 모니터링·로깅, SLA/SLO, 온콜, Incident/Problem Management |
| 네트워크·보안 | VPN/Direct Connect, WAF, IAM, 접근제어, DevSecOps/SOC |
| 고객·도메인 | 게임/스타트업/금융/공공/제조 등, 트래픽·규제·운영상의 요구 |
| 채용 | 신입 지원 가능 여부, 엔지니어 직무, 상주/교대근무, 요구 경력·스택 |

**우선 조사 후보(순위 아님):** 메가존클라우드, 베스핀글로벌, 클루커스, 스마일샤크, 안랩클라우드메이트, GS네오텍.  
**주의:** 회사 전체가 특정 기술을 쓴다는 이유만으로 해당 회사의 모든 팀에서 Kubernetes, SRE, 보안관제 경험을 할 수 있다고 단정하지 않는다.

## 4. 다음 단계: 사례 분석 템플릿
