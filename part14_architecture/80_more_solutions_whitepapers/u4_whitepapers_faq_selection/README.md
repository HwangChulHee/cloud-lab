## Scenario 문제 접근

강의에서 강조하는 방식:

```text
1. 명확히 틀린 선택지를 제거
2. 남은 선택지 중 요구사항에 가장 맞는 것을 선택
3. 지나치게 복잡한 solution을 경계
4. 문제의 핵심 requirement를 먼저 찾음
```
