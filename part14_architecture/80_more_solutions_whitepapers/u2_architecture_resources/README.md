# u2. AWS Architecture Resources

강의는 더 많은 실제 architecture 예시를 보기 위한 AWS 자료를 안내한다.

## AWS Architecture Center

Classic / Serverless를 포함한 다양한 reference architecture를 확인하는 출발점이다.

## AWS Solutions

특정 문제를 해결하기 위한 AWS Solution 구현 예시를 볼 수 있다.

강의의 Instance Scheduler on AWS도 AWS Solution 예로 등장한다.

## 학습 관점

reference architecture를 그대로 외우기보다 다음을 본다.

```text
요구사항은 무엇인가?
왜 이 서비스가 선택됐는가?
동기/비동기 경계는 어디인가?
state는 어디에 있는가?
HA와 scaling은 어떻게 처리하는가?
```

## 기억할 문장

> Reference architecture는 정답 암기용이 아니라 서비스 선택 근거와 trade-off를 읽는 자료다.
