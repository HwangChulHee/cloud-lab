# u3. AWS Trusted Advisor

AWS Trusted Advisor는 별도 agent 설치 없이 AWS Account를 고수준으로 분석하고 recommendation을 제공한다.

강의에서 제시하는 6개 category:

```text
Cost Optimization
Performance
Security
Fault Tolerance
Service Limits
Operational Excellence
```

## Support Plan

강의에서는 Business / Enterprise Support Plan에서 full set of checks와 AWS Support API 기반 programmatic access를 사용할 수 있다고 설명한다.

## Well-Architected Tool과 차이

```text
Trusted Advisor
→ AWS Account/resource 상태 기반 recommendation

Well-Architected Tool
→ workload architecture를 6 Pillar 질문으로 review
```

## 기억할 문장

> Trusted Advisor는 account 상태를 점검해 비용·성능·보안·내결함성 등의 recommendation을 제공한다.
