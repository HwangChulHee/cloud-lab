# 79. AWS Well-Architected Framework

AWS Well-Architected Framework는 workload를 **6개 Pillar 관점에서 검토하는 architecture best-practice framework**다.

## 6 Pillars

```text
1. Operational Excellence
2. Security
3. Reliability
4. Performance Efficiency
5. Cost Optimization
6. Sustainability
```

강의에서는 이 Pillar들을 단순 trade-off 관계가 아니라 함께 개선되는 **synergy**로 설명한다.
