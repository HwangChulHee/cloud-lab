# u3. AWS Well-Architected Tool

AWS Well-Architected Tool은 architecture를 6 Pillar 기준으로 review하는 **무료 도구**다.

강의 흐름:

```text
Workload 선택
   ↓
질문에 답변
   ↓
6 Pillars 기준 검토
   ↓
Advice / Documentation / Videos
   ↓
Report / Dashboard
```

## 목적

```text
architecture review 구조화
risk 확인
best practice guidance 확인
개선 작업 추적
```

## 기억할 문장

> Well-Architected Framework가 원칙이라면 Well-Architected Tool은 실제 workload를 그 원칙으로 review하는 도구다.
